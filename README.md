## 📖 Project Overview
The **Flat Management System (FMS)** is a simple web development project created during my training period at **Atos Syntel Private Limited**.  
It demonstrates basic web technologies and deployment practices using GitHub Pages.

---

## ⚙️ Technologies Used
- **HTML** – Structure and layout  
- **CSS** – Styling and design  
- **JSP** – Dynamic page rendering  
- **JavaScript (Basic)** – Smooth scrolling functionality  
- **GitHub Pages** – Deployment and hosting  

---

## 🚀 Features
- Clean and responsive layout  
- Basic navigation with scroll effect  
- JSP integration for dynamic content  
- Hosted and accessible via GitHub Pages
